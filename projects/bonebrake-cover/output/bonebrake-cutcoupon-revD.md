# Bonebrake artwork cut coupon — acceptance sheet (Rev D)

Generated by cutcoupon.py at Rev D — regenerate, don't hand-edit.
Program: `bonebrake-cutcoupon-revD.dxf`. Blank 8.500 x 11.500, 11ga mild steel, same lot as the panels.

## Why this exists

The generation gate says no run of too-thin material may exceed **0.957"** (8 x material thickness). That is reasoning about heat sinking, not a measurement. The artwork currently clears it 3.8x (longest steel run 0.251), but the limit itself has never been proven on this machine. Zone C locates it.

## Cut it the way the panel will be cut

- **TWO ops, ONE gcode file.** Operations are not programs: post the SETUP
  and Fusion writes both ops into a single NC file, in browser-tree order.
  Same torch in both, so no tool change. Put the pilot op FIRST, so the holes
  are pierced while the blank is still fully attached and rigid.
- The DXF ships on two layers — **`PILOTS`** (2 circles) and **`CUTS`**
  (everything else). Insert DXF with the **one-sketch-per-layer** option on, then
  each op selects a whole sketch. Never pick contours by hand on this file.
- The 2 pilot circles go in their own holes-only op:
  Sideways Compensation = **Center**, Lead-In (Entry) and
  Lead-Out (Exit) both **unchecked**, Pierce Clearance = **0.00 in**. The
  default 0.059 pierce clearance plus a 0.020 lead needs 0.079 inside a
  0.0625 radius, so Fusion discards the pass and the hole never
  gets cut. Everything else (art, outline, ladder slots) is a normal-comp op
  with standard leads, and must NOT include the pilot circles.
- Same CAM setup as the panel programs (see the CAM sheet), same consumables
  at their current wear state — note the tip hours on this sheet.
- **Same cut ordering and the same back-to-back timing.** A coupon cut
  leisurely, with cooling between adjacent contours, tells you nothing about a
  panel cut continuously. This is the usual way coupons mislead.
- Same hold-down as the panel. Do not separate the zones.
- Orientation key: the clipped corner is TOP LEFT, art side up.

## Acceptance — measure, don't eyeball

1. **Measured kerf.** Caliper a ladder SLOT (drawn 0.180) and a surviving
   WEB (drawn width, table above). With normal comp the finished size matches
   the drawing only when the kerf set in CAM equals the real kerf; if the real
   kerf is wider, slots come out wide and webs come out narrow by the same
   amount. So: real kerf = 0.055 + (slot_measured - 0.180).
   The design assumes **0.055"**, which sets MIN_SLIVER (2x kerf),
   the ladder floor, the pilot-size check and every post-kerf web figure — so if
   this comes back materially different, `PLASMA_KERF` changes and the panel
   gets re-checked before cutting. NOTE: a consumable's stated orifice (e.g.
   0.8 mm) is NOT the kerf — the arc flares, so cut width runs wider, typically
   1.5-2x the bore. Measure, don't read it off the box.
2. **Ladder survival** per cell, table above.
3. **Flatness across the WHOLE coupon** — straightedge + feeler, record the
   worst gap and where. This is the one that scales to the panel: what kills
   the assembly is the face not seating on the frame, not an ugly cut.
4. **Local curl** at each surviving thin feature — a web can survive and still
   stand proud.
5. **Dross / tags** on the thin features, and whether they clean up without
   eating the feature.
6. **Detail loss** — compare zone A and B against the DXF. Tips will round;
   record how much, because that is what the customer sees.

## What this coupon cannot tell you

Cumulative distortion over 41.125". A 11.5" piece cannot reproduce the bow of a full panel. The coupon bounds the local question — do these features survive, and where is the limit. Whole-panel flatness is answered only by the panel, and the lever there is cut ordering in the dense band so adjacent contours are not run consecutively.
