# Bonebrake Cover — CAM Sheet  (Rev D, 8.500 x 41.125)

Generated by bonebrake_assembly.py at Rev D — regenerate, don't hand-edit.
Import each DXF: Insert DXF, **Units = Inch** (dialog ignores the file's declared units), and turn ON the option that makes **one sketch per layer**.

Every DXF ships on two layers so the two ops never have to be separated by hand:

| Layer | Contents | Which op |
|---|---|---|
| `PILOTS` | the pilot circles, nothing else | Op 1 |
| `CUTS` | art, outline, everything else | Op 2 |

Select the whole sketch for each op. Do NOT pick contours individually — on a file with dozens of them that is how pilots end up in the profiles op by accident.
Post programs named to match the rev — `bonebrake-face-revD.gcode`, `bonebrake-middle-revD.gcode` (Fusion suggests "1001"; overwrite it — .gcode is our extension, it's what Jimmie expects) — and attach to the PPBO Job, removing superseded revs.

## Programs to cut

| Program | Material | Qty | Blank W | Blank H |
|---|---|---|---|---|
| bonebrake-face-revD.gcode | 11ga mild steel | **1** | 8.5" | 41.5" |
| bonebrake-middle-revD.gcode | 11ga mild steel | **1** | 8.5" | 41.5" |

Cut EXACTLY the quantities above — nothing else on the drive is current. Blank sizes are the part bbox (8.500 x 41.125 exact) rounded up to the next 1/2"; leave your usual edge/start clearance beyond that.

Two ops per panel, **one gcode file per panel**. Operations are not programs: post the
SETUP, not the individual ops, and Fusion writes both into a single NC file in
browser-tree order. Same tool (the torch) in both, so there is no tool change between
them — only comp and lead settings differ, and those are already baked into the
toolpath coordinates by the time it posts. Jimmie runs one file per panel.

**Order matters: drag Op 1 (pilots) ABOVE Op 2 (profiles).** Pierce the holes while the
blank is still fully attached and rigid; cut the outline first and you are piercing a
part that is already free to move and has taken heat.

## Op 1 — pilot holes only (small-hole recipe, both panels)

Select: the **`PILOTS`** sketch — the 14x 1/8" pilot circles, and NOTHING else.

| Setting (tab → group) | Value |
|---|---|
| Passes → Sideways Compensation | **Center** |
| Linking → Leads → Lead-In (Entry) | **unchecked** |
| Linking → Leads → Lead-Out (Exit) | **unchecked** |
| Linking → Piercing → Pierce Clearance | **0.00 in** |

Why: normal comp refuses profiles under ~3/16" and the default pierce clearance can't fit inside the pilot. Center comp cuts ON the line — the hole opens to ~pilot + kerf (0.180"), rough is fine: every pilot gets drilled to final size per the drill schedule.

## Op 2 — profiles (normal op, per panel)

| DXF | Select |
|---|---|
| bonebrake-face-revD.dxf | art cutouts + outer profile — cut art (inside profiles) BEFORE the outline |
| bonebrake-middle-revD.dxf | outer profile only |

Settings: normal Sideways Compensation (kerf 0.055" stays in CAM), standard leads/pierce. Select the **`CUTS`** sketch — it already excludes the pilots, which are Op 1's.

**Check the kerf set in the tool before posting.** A coupon posted 2026-10-16 carried `jetDiameter = 0.0315` (0.8 mm — the NOZZLE BORE) and compensated for a 0.0472" kerf, against the 0.055" this design assumes. A consumable's stated orifice is not its cut width; the arc flares wider. The coupon settles it — acceptance item 1 on the coupon sheet.
